# Laboratorio 06 Clases Abstractas e Interfaces

Este laboratorio es la continuación de los Labs 04 y 05.  
En ellos trabajamos con herencia y polimorfismo usando la clase `Personaje` como concreta.  
Ahora refinamos el diseño convirtiéndola en **abstracta** y agregando **interfaces** para definir capacidades opcionales.

---

## Objetivo
- Definir y usar clases abstractas con métodos abstractos y concretos.  
- Implementar interfaces para capacidades adicionales (`Hechicero`, `Sanador`).  
- Combinar clase abstracta + interfaz en una jerarquía coherente.  
- Demostrar polimorfismo y uso de `instanceof`.
